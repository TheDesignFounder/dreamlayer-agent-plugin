# print on demand artwork

Read [the workflow contract](references/workflow-contract.md) for setup, billing, recovery and output checks.

Ask for intended physical size and the print provider's pixel requirements when the user needs final production files. Generate artwork concepts, with background_remove as a separate operation if transparency is needed. Inspect actual pixel dimensions and alpha; calculate effective PPI as pixels divided by inches. Do not label the output print-ready until it meets the specific supplier's requirements. Upscaling does not guarantee original detail. Do not promise vectors, seamless repeat patterns, embroidery files, color-profile conversion or store publishing. If requirements exceed supported output, provide the concept and state the remaining production step.
