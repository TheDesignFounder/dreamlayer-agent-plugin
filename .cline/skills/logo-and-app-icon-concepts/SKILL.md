# logo and app icon concepts

Read [the workflow contract](references/workflow-contract.md) for setup, billing, recovery and output checks.

Collect brand name, audience, tone, silhouette and palette; use a small explicitly authorized number of concepts. Request original marks without copying an existing brand. Prefer symbol exploration first; add precise lettering separately if generation misspells it. Generate a square icon concept and inspect it at small size. Remove background in a separate authorized operation if required. Export raster images and explain whether alpha is present. Do not describe a PNG as SVG, a scalable vector master, a cleared trademark or exclusive ownership. A supplied mark should be edited only as requested, preserving its identity.
