# marketing image variations

Read [the workflow contract](references/workflow-contract.md) for setup, billing, recovery and output checks.

Define audience, offer, destination placement, brand colors, required copy, aspect ratio and authorized variant count. Map output ratios to the supported ratios; use an explicit crop/resize step when a placement needs exact pixels. Generate or edit one approved reference direction and inspect each variation. Check text and product claims. For precise typography, use generated imagery as a background and add text in the project's design/code tools. Save an output manifest with brief, filename, dimensions and review status. No ad account upload, spend or campaign launch is implied.
