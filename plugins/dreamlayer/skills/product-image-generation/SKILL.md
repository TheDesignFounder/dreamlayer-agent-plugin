# product image generation

Read [the workflow contract](references/workflow-contract.md) for setup, billing, recovery and output checks.

Require a reference photo for a real product. Identify the product details that must remain: shape, label, logo, color, count and proportions. Use image_to_image with a specific setting and composition; use background_remove for a clean cutout. Inspect the result against the reference and flag altered details before it is used in a listing. DreamLayer generation is not a guarantee of SKU fidelity. Export local files; do not publish listings or claim storefront integration. Generate one reviewable candidate before expanding an authorized batch.
